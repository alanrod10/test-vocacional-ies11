# Archivo histórico — Test Vocacional IES N.° 11

## Propósito

Esta instancia conserva el trabajo realizado para la **Expo Educativa 2026 del IES N.° 11, Jujuy**. Su finalidad es presentar la experiencia finalizada, sus resultados agregados y su documentación, sin aceptar nuevas evaluaciones ni permitir la eliminación de datos desde la aplicación.

## Estado preservado

| Componente | Estado en el archivo histórico |
| --- | --- |
| Participación pública | Cerrada; el servidor rechaza cualquier nuevo envío. |
| Estadísticas públicas | Disponibles en modo de lectura para conservar el cierre de la experiencia. |
| Datos individuales | Conservados en la base institucional; no se muestran públicamente. |
| Exportación CSV | Disponible solo con la contraseña privada de coordinación. |
| Reinicio de resultados | Bloqueado en interfaz y servidor. |
| Resultados compartidos | Se conservan para las URL ya generadas, sin crear evaluaciones nuevas. |

## Regla de preservación

No se deben modificar preguntas, catálogo, puntajes, registros, analítica ni la interfaz de esta instancia histórica. Toda mejora futura debe realizarse en un proyecto independiente.

## Cómo iniciar la evolución permanente

1. Crear una **nueva instancia** del proyecto desde un checkpoint de este archivo histórico.
2. Asignarle un **dominio propio**, una **base de datos nueva** y secretos administrativos nuevos. Nunca reutilizar la base de datos histórica.
3. Mantener `HISTORICAL_ARCHIVE.enabled: true` en este repositorio y configurar la nueva instancia con un modo operativo distinto.
4. Versionar por separado el nuevo catálogo, cuestionario, métricas y cambios metodológicos.
5. Conservar este repositorio y su checkpoint como referencia verificable de la Expo Educativa 2026.

> La copia para evolución parte del mismo código y documentación, pero no debe compartir datos identificatorios, acciones administrativas ni registros con el archivo histórico.
