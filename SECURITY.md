# Seguridad y tratamiento responsable de datos

Este es un repositorio institucional privado. Las exportaciones del test pueden contener información personal y, por lo tanto, no deben cargarse al repositorio, adjuntarse en incidencias, copiarse en conversaciones ni utilizarse como datos de prueba.

## Reglas obligatorias

| Riesgo | Regla aplicable |
|---|---|
| Datos identificatorios | Mantener CSV, respaldos y consultas fuera de Git y en almacenamiento institucional controlado. |
| Secretos | No versionar contraseñas, claves, tokens ni archivos `.env`. Usar únicamente el gestor seguro aprobado. |
| Acciones administrativas | Proteger la exportación y el reinicio; conservar la bitácora y el respaldo requerido. |
| Publicación | Compartir solo documentos con datos agregados y sin categorías que permitan reidentificación. |
| Incidentes | Informar de inmediato al responsable técnico o autoridad institucional sin adjuntar datos sensibles. |

Si se detecta una exposición, se debe revocar o rotar la credencial afectada, preservar la evidencia mínima necesaria, evaluar el alcance y documentar la corrección. No se deben intentar correcciones que borren evidencia sin una decisión institucional.
