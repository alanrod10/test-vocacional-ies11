# Operación y mantenimiento

La operación cotidiana consiste en mantener disponible el test, observar el tablero agregado y resguardar las acciones administrativas. El usuario público puede completar el cuestionario, obtener su resultado y descargar materiales individuales. No puede acceder a la base ni ejecutar exportaciones o reinicios sin la contraseña correspondiente.

| Proceso | Control mínimo |
|---|---|
| Actualización de preguntas | Versionar texto, conservar historial y ejecutar pruebas. |
| Cambio de catálogo | Confirmar la oferta institucional, crear versión y no reinterpretar registros anteriores. |
| Exportación CSV | Solicitar contraseña y registrar la acción de auditoría. |
| Reinicio de resultados | Exigir doble confirmación, contraseña y respaldo CSV previo. |
| Cierre de actividad | Generar informe agregado, mover exportación a almacenamiento institucional y documentar responsables. |

Si la aplicación presenta errores de servidor, se deben revisar los registros técnicos, reproducir el problema en un entorno controlado y ejecutar la suite de pruebas antes de guardar una nueva versión. Las acciones correctivas no deben incluir secretos en mensajes, capturas ni commits.
