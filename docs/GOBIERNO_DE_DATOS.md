# Gobierno de datos y privacidad

La base del Test Vocacional IES N.° 11 se utiliza con una finalidad institucional de orientación y análisis agregado. El acceso debe seguir el principio de mínima necesidad: solo las personas autorizadas para administrar o analizar la experiencia pueden consultar exportaciones con campos de registro.

## Clasificación y destino

| Clase de información | Ejemplos | Destino permitido |
|---|---|---|
| Personal | Nombre, apellido, edad, localidad, fecha individual, ID | Base e exportaciones institucionales protegidas. Nunca Git ni informes públicos. |
| Operativa sensible | Contraseña administrativa, tokens, respaldos, bitácora detallada | Gestor seguro y acceso de administración autorizado. |
| Agregada | Conteos, porcentajes, áreas, Top 3, versiones | Informes institucionales y, tras revisión, difusión pública. |
| Técnica pública | Código saneado, metodología, esquemas no sensibles | Repositorio público derivado, si la institución lo aprueba. |

## Reglas de publicación

Los gráficos deben representar categorías agregadas. Si una partición produce menos de tres casos, no debe mostrarse de forma aislada. Las fechas individuales, localidades detalladas y combinaciones de atributos que puedan facilitar reidentificación se excluyen de cualquier material de circulación general.

## Retención y resguardo

La institución debe definir por escrito quién conserva las exportaciones, durante cuánto tiempo y con qué procedimiento de baja segura. Los reinicios requieren respaldo previo porque los datos eliminados no se recuperan desde la aplicación. El respaldo debe ubicarse fuera del repositorio, con fecha, responsable y control de acceso documentados.
