# Guía breve: cómo se pondera el Test Vocacional IES N.° 11

## Idea central para explicar en clase

> El test no “adivina” una carrera ni usa una única respuesta para decidir. Identifica intereses a partir de 14 situaciones y compara ese perfil con las actividades propias de cada tecnicatura.

## Cómo responde una persona

Cada pregunta presenta una situación cotidiana o de práctica: resolver un problema, organizar una tarea, trabajar con datos, acompañar a personas, crear una propuesta o mejorar un servicio. La persona elige la opción que más la representa.

Cada opción tiene asociado un conjunto de intereses del modelo **RIASEC**:

| Dimensión | Significado sencillo | Ejemplos de intereses |
|---|---|---|
| R — Realista | Hacer, construir, operar o trabajar con herramientas y procesos. | Producción, mantenimiento, energía, laboratorio. |
| I — Investigador | Analizar, observar, resolver problemas y trabajar con evidencia. | Datos, diagnósticos, análisis, investigación. |
| A — Artístico | Crear, diseñar, comunicar y expresar ideas. | Diseño, gastronomía, patrimonio, propuestas visuales. |
| S — Social | Acompañar, enseñar, cuidar y trabajar con personas. | Salud, enfermería, gerontología, promoción comunitaria. |
| E — Emprendedor | Liderar, organizar, impulsar proyectos y tomar decisiones. | Turismo, hotelería, gestión y coordinación. |
| C — Convencional | Ordenar, registrar, planificar y controlar información o procesos. | Estadísticas, administración, registros y calidad. |

## Cómo se calcula el resultado

1. **Se suman las señales de interés.** Cada respuesta elegida aporta puntos a una o más dimensiones RIASEC.
2. **Se obtiene un perfil de intereses.** Al final de las 14 preguntas, la persona tiene una combinación propia de las seis dimensiones.
3. **Se compara con cada tecnicatura.** Cada una de las 18 ofertas vigentes del IES N.° 11 tiene un perfil de referencia según sus tareas, materias y campo profesional.
4. **Se consideran anclajes prácticos.** Algunas preguntas describen actividades muy propias de determinadas tecnicaturas; esas coincidencias ayudan a diferenciar propuestas cercanas.
5. **Se ordenan las coincidencias.** El sistema muestra las tres tecnicaturas con mayor afinidad, con puntajes comparables sobre 100.

## Qué no hace el test

- No hay respuestas correctas o incorrectas.
- No define el futuro de una persona ni reemplaza una conversación de orientación.
- La opción **“Ninguna de estas opciones me representa”** no suma puntos. Si todas las respuestas son neutrales, el sistema no genera una recomendación para evitar un resultado inventado.

## Cómo explicar la confiabilidad

La ponderación es transparente: las respuestas mantienen sus códigos y pesos; por eso una mejora de redacción no cambia el cálculo. Además, los resultados históricos quedan identificados por versión de cuestionario y catálogo, de modo que la analítica puede compararse con honestidad.

## Respuesta corta para el profesor

> “Usamos 14 situaciones y el modelo RIASEC. Cada opción suma señales de interés, luego comparamos ese perfil con los perfiles de referencia de las tecnicaturas del IES N.° 11. El resultado muestra afinidades, no una decisión obligatoria; por eso damos un Top 3 y una explicación de cada propuesta.”
