# Guía general — Test Vocacional IES N.° 11

## ¿Qué es?

El **Test Vocacional IES N.° 11** es una aplicación web que ayuda a explorar, de forma inicial, las **19 Tecnicaturas Superiores** del IES N.° 11. Está diseñada para orientar a cada persona hacia propuestas que se relacionen con sus intereses, formas de resolver problemas y actividades que disfruta realizar.

> El test no define una carrera de manera definitiva. Ofrece una orientación inicial y propone alternativas para seguir investigando, conversar con docentes y tomar una decisión informada.

La aplicación puede utilizarse desde celular, tableta o computadora en [vocatest11-j6zpasaq.manus.space](https://vocatest11-j6zpasaq.manus.space).

## Cómo se utiliza

La persona inicia completando datos básicos: nombre, apellido, edad, sexo, localidad y situación educativa. Antes de continuar, acepta un consentimiento para el uso institucional de sus datos. La aplicación **no solicita WhatsApp**.

Luego responde **14 preguntas situacionales**. En vez de preguntar únicamente qué carrera le gusta, el test plantea actividades, decisiones y situaciones concretas: resolver un problema técnico, analizar información, organizar una tarea, acompañar a otras personas o crear una propuesta. La barra de progreso indica el avance y permite volver a una respuesta anterior.

| Parte del recorrido | Qué recibe la persona |
|---|---|
| Cuestionario | Preguntas claras sobre intereses y maneras de actuar. |
| Resultado principal | La tecnicatura con mayor afinidad. |
| Perfil profesional | Explicación de tareas, materias y posibles campos laborales. |
| Comparación | Tres afinidades principales para conocer alternativas cercanas. |
| Material descargable | Informe PDF y tarjeta visual para compartir. |

## Cómo se calcula el resultado

Cada respuesta aporta señales relacionadas con intereses prácticos, analíticos, creativos, sociales, emprendedores y organizativos. El motor vocacional combina esas señales con los perfiles de las tecnicaturas y ordena las tres opciones con mayor afinidad.

Las propuestas se agrupan en cinco áreas: **Tecnología e Innovación; Salud y Bienestar; Administración y Servicios; Producción y Ambiente; y Educación, Cultura y Diseño.** La última pregunta consulta el interés por estudiar en el IES N.° 11 y se utiliza para conocer el interés general, sin modificar la recomendación.

## Qué muestra el resultado

Al finalizar, la aplicación presenta una tecnicatura principal y dos opciones cercanas. Cada resultado incluye una explicación profesional ampliada y sencilla: qué problemas se trabajan, tareas habituales, materias principales y contextos laborales posibles en Jujuy y el NOA.

La comparación final ayuda a observar diferencias entre las tres afinidades. En computadoras se muestra como una tabla con puntaje, área, enfoque, materias clave y campo laboral. En celular se adapta a fichas apiladas para facilitar la lectura sin desplazamiento lateral.

## PDF, tarjeta y códigos QR

La persona puede descargar un **informe PDF** con su orientación completa. También puede descargar una tarjeta visual para redes sociales, con un resumen de la tecnicatura principal.

El resultado incorpora un QR que abre la tarjeta desde el celular. Por su parte, el QR de la página principal y del afiche permite ingresar directamente al test.

## Privacidad y panel institucional

Los nombres y apellidos se guardan de forma protegida y no se muestran en la página pública. El panel de analítica presenta solo datos agrupados, como cantidad de evaluaciones y afinidades más frecuentes. Cuando existen pocas respuestas, algunos datos demográficos se ocultan para evitar identificaciones indirectas.

La exportación completa en CSV y el reinicio de las métricas requieren una contraseña privada de coordinación. Así, la herramienta combina una experiencia abierta para visitantes con protección de las acciones administrativas sensibles.

## Tecnología utilizada

La aplicación se desarrolló con **React y TypeScript** para la interfaz, **Express y tRPC** para la comunicación con el servidor, **Drizzle ORM** para la persistencia de datos y herramientas para generar PDF, tarjetas PNG, QR, animaciones y gráficos de analítica.

**En síntesis:** el Test Vocacional IES N.° 11 ayuda a conocer la oferta académica de forma personalizada, clara y accesible, sin reemplazar la decisión personal ni el acompañamiento institucional.
